# Sleep Return Wizard Pages

A static JavaScript version of the Sleep Return Wizard. The report is generated in the browser, so no Python server or installation is needed.

## Access online

Use the public GitHub Pages site: [Sleep Return Wizard](https://ezbemck.github.io/Sleep_Return_Wizard_Pages/).

## Run locally

Open `index.html` directly, or serve this folder with Python's built-in server:

```sh
python3 -m http.server 8000
```

Then open http://127.0.0.1:8000.

Questionnaire answers are processed in the browser and are not saved or sent to a server.
